Everything here is the real model from the deterministic engine — generate() synthesizes 10,000 card transactions, a from-scratch GradientBoostingClassifier fits 120 depth-3 trees on the logistic loss, and each tree is exported with its raw split thresholds. The browser traverses all 120 trees, sums the shrunken leaf values onto the base log-odds, and applies the logistic link — the exact same math as gbm.decision_margin(). The review panel scores the genuine held-out test set (– transactions, – fraud). No server, no libraries.
